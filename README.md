# Personal Details App

A simple Expo and React Native profile app for displaying personal details and
managing a profile picture and points total.

## Features

- Shows a profile name and email address.
- Opens the device's email app when the email address is selected.
- Lets the user choose and crop a profile picture from the photo library.
- Saves the selected picture and points total on the device between launches.
- Adds a point with the floating action button.

## Requirements

- Node.js and npm
- Expo Go on a compatible iOS or Android device, or an emulator

## Run locally

```sh
npm install
npm start
```

Scan the QR code with Expo Go, or press `a` or `i` in the Expo terminal to open
the app in an Android or iOS emulator.

## Lint

```sh
npm run lint
```
